# v0.3 release gate

AgentCapDiff v0.3 is complete only when the implementation and the final pull-request head satisfy all of the evidence below. The merge itself remains blocked until the required GitHub checks are green on the final release-state commit.

## Semantic adapter gate

- Equivalent filesystem privileges normalize to the same capability ID, risk, restricted scope, and policy semantics across MCP, OpenAI API, OpenAI Agents SDK, Claude, LangChain, LangGraph-compatible, and CrewAI-style static metadata.
- Equivalent external-network privileges normalize consistently across the same adapter set.
- Dynamic/unconstrained path scope stays `unknown` for every supported adapter.
- Ambiguous `args_schema` metadata preserves the detected capability/scope but remains generic and lower-confidence instead of guessing framework provenance.
- A framework representation cannot turn an existing `deny` policy decision into a weaker decision.

These properties are exercised by `tests/test_adapter_conformance.py` together with the existing universal-schema, scope, snapshot, parser-hardening, and security-regression suites.

## Compatibility gate

- Universal capability schema remains explicitly versioned as schema `1`.
- v0.2 capability IDs and fingerprints remain readable in snapshots.
- `capability_records` adds scope/evidence/confidence without reinterpreting the legacy capability identity.
- Unsupported schema versions fail explicitly; unknown scope/confidence fails conservatively.
- Framework adapters add provenance evidence without weakening normalized privilege meaning.

## Safety gate

- Analysis remains JSON/YAML static-only; no target SDK import or target-code execution is introduced.
- Discovered endpoints are not contacted and DNS is not resolved.
- No credentials or secrets are collected for adapter inference.
- Runtime-generated, unsupported, or ambiguous behavior is not promoted to known-safe/restricted merely to claim adapter coverage.

## Required final checks

Before merge, the **final release-state PR head** must have all of these green:

1. CI on Python 3.11 / 3.12 / 3.13, including Ruff, pytest, and CLI smoke scan.
2. CodeQL.
3. Agent capability policy (self-policy).
4. PR capability diff.
5. Project state consistency.

`ROADMAP.md`, `pyproject.toml`, runtime `__version__`, README status, and CHANGELOG are finalized to v0.3.0 only in the same PR after the implementation pass has already succeeded.
