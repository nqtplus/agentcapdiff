# v0.2 release gate evidence

This file records the evidence expected before v0.2 is merged to `main`.

- Malformed/oversized/pathological inputs fail safely: `tests/test_discovery.py`, `tests/test_fuzz_hardening.py`.
- No target-code execution or input-triggered network access: static discovery only plus `tests/test_security_regressions.py`.
- Filesystem scope distinguishes `restricted`, `broad`, `unknown`: `tests/test_scopes.py`.
- Network scope distinguishes exact/wildcard restricted, broad, and unknown: `tests/test_scopes.py`.
- Semantic scope expansion is represented in snapshot diffs and Markdown review output: `tests/test_scopes.py`, `tests/test_scope_markdown.py`.
- Traversal and symlink edge cases are conservative: `tests/test_scopes.py`, `tests/test_discovery.py`.
- Markdown output injection remains escaped: `tests/test_formats.py`, `tests/test_fuzz_hardening.py`, `tests/test_security_regressions.py`.
- Sanitized MCP fixture corpus: `tests/fixtures/mcp/` and `tests/test_mcp_fixtures.py`.
- CI runs all tests on Python 3.11, 3.12, and 3.13; CodeQL, AgentCapDiff self-policy, PR capability diff, and project-state consistency are separate required evidence surfaces.

The release must not be claimed complete until the pull request checks are green and the merged `main` state is read back.
