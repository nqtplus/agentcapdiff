# AgentCapDiff v0.2.0

v0.2 adds semantic filesystem/network scope evidence and closes the initial hostile-input safety foundation.

Highlights:
- filesystem and external-network scopes are modeled separately from capability IDs
- static scope states are `restricted`, `broad`, or `unknown`
- snapshot diffs report scope changes and conservatively flag proven expansions
- ambiguous/dynamic/traversing scope stays unknown
- sanitized MCP fixture corpus expands real-world schema coverage
- deterministic fuzz/property and security regression tests cover parser, path, output, and no-network/no-execution invariants
- project-state CI prevents roadmap/version drift

Security posture remains intentionally conservative: AgentCapDiff is static review evidence, not runtime enforcement or proof that an agent is safe.
